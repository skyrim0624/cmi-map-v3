# CMI Map - 清迈华人社区共建生活地图

一款面向清迈华人社区的共建生活地图移动端 Web 应用。社区成员在地图上标记自己推荐的地方，留下推荐理由与照片，共同绘制一张属于社区的清迈生活地图。

## 功能特点

### 🗺️ 地图查看模式
- 百度地图全屏展示所有推荐地点
- 不同分类用不同颜色标记点区分
- 点击标记点查看预览卡片
- 点击预览卡片进入详情页

### 📋 列表查看模式
- 按分类筛选推荐（全部/吃饭/咖啡/户外/拍照/涂鸦/市集/放松/运动/宝藏）
- 卡片式展示推荐列表
- 显示推荐理由、地点名称、推荐人

### 📍 地点详情页
- 照片轮播展示
- 完整推荐理由展示
- 多人推荐独立展示
- 一键导航到百度地图

### ✏️ 标记界面
- 地图选点（十字准星）
- GPS 自动定位
- 填写地点信息：名称、分类、推荐理由、照片（最多3张）
- 自动记忆用户名
- 图片自动压缩（最大1MB）

### 👤 个人页面
- 查看贡献统计
- 查看个人推荐列表

## 技术栈

- **前端框架**: React + TypeScript
- **UI 组件**: shadcn/ui + Tailwind CSS
- **地图服务**: Leaflet + OpenStreetMap
- **后端服务**: Supabase (数据库 + 存储)
- **构建工具**: Vite

## 地图特性

- 使用 Leaflet + OpenStreetMap 提供流畅的地图体验
- 极简纯色地图风格，只显示道路和用户标记点
- 支持平滑缩放和拖动
- 点击"导航到这里"跳转到 Google Maps 导航

## 设计风格

采用日系极简手账风格：
- 米白纸张质感底色
- 薰衣草紫强调色 (#9B8EC6)
- 大面积留白，呼吸感强
- 引用样式的推荐理由展示
- 轻微阴影的卡片设计

## 使用说明

### 查看推荐
1. 打开应用默认进入地图查看模式
2. 点击地图上的标记点查看预览
3. 点击右上角列表图标切换到列表模式
4. 在列表模式中可以按分类筛选

### 添加推荐
1. 点击左下角编辑按钮进入标记界面
2. 移动地图，将十字准星对准要推荐的位置
3. 填写地点信息（名称、分类、推荐理由必填）
4. 可选上传1-3张照片
5. 点击"画上去"提交

### 查看个人贡献
1. 点击底部中央的用户头像
2. 查看贡献统计和推荐列表

## 数据存储

- **推荐数据**: 存储在 Supabase 数据库
- **图片文件**: 存储在 Supabase Storage
- **用户名**: 本地存储（localStorage）

## 开发说明

### 安装依赖
```bash
pnpm install
```

### 启动开发服务器
```bash
pnpm dev
```

### 构建生产版本
```bash
pnpm build
```

### 代码检查
```bash
pnpm lint
```

## 环境变量

应用已自动配置 Supabase 连接，无需手动设置环境变量。

## 注意事项

1. **图片上传**: 自动压缩至1MB以内，转换为WEBP格式
2. **用户名**: 首次输入后会自动记忆，可随时修改
3. **GPS定位**: 需要浏览器授权位置权限
4. **地图导航**: 点击"导航到这里"会跳转到 Google Maps 进行导航
5. **地图缩放**: 支持流畅的缩放和拖动操作
