Leaflet markercluster:
"When you click a cluster at the bottom zoom level we spiderfy it so you can see all of its markers."
"spiderfyOnMaxZoom" applies only to the max zoom level.
If you want to spiderfy at ANY zoom level upon clicking, you set:
zoomToBoundsOnClick: false 
spiderfyOnMaxZoom: true (or doesn't matter)
Actually, in leaflet.markercluster, if you set zoomToBoundsOnClick: false, clicking on a cluster triggers "clusterclick" event. Wait, does it spiderfy by default when zoomToBoundsOnClick is false?
Usually:
```javascript
clusterGroup.on('clusterclick', function (a) {
    a.layer.spiderfy();
});
```
