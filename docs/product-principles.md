# CMI Map 产品原则收敛计划

## Summary

把 2026-04-26 和 2026-05-27 的方向思考收敛为一句核心判断：**CMI Map 不做广告地图，也不做 AI 行程工具；它是一张让 CMI 社区成员把清迈生活时刻留下来的社区记忆地图。**

本轮方向应从“别人建议的可变现功能”回到“创始人真正想做的产品气质”：干净、慢、有人味、轻社交、像手账，也像开放世界里的留言。最新产品主线见 [CMI Map 社区生活记忆方向](./community-memory-map-strategy.md)。

## Key Changes

- **产品定位**：从“社区推荐工具”升级为“带地点的社区生活记忆流”。
- **商业边界**：不引入普通商家广告位；未来如有商业化，也必须服务于地图气质，例如精选合作、赞助路线、贴纸/手账个性化，而不是信息流广告。
- **AI 边界**：AI 路线规划暂不作为核心方向；若加入，只能作为辅助发现工具，不能把产品变成旅行规划机器人。
- **核心功能优先级**：
  1. 留个彩蛋：图 + 位置 + 一句话的极简发布闭环
  2. 首页社区新鲜事：最近彩蛋、活动返图、地点推荐
  3. 附近地图：附近彩蛋 + 目的地推荐 + 活动痕迹
  4. 活动相册与分享卡：把共同经历沉淀成可转发的地图记忆
  5. 社区背书地点页：谁推荐过、最近体验、适合谁、附近彩蛋
- **NCC 路演口径**：重点讲“为什么不做广告地图”和“为什么 AI 时代反而需要有人的地图”，而不是堆功能路线图。

## Product Principles

- **人味优先于效率**：推荐不是最短路径答案，而是一个人真实生活经验的留下。
- **表达优先于整理**：先让用户把这一刻留下来，再做地点、活动、主题图层和攻略归档。
- **小社区优先于大平台**：先服务好 CMI 的清迈生活圈，社区长大，地图再一起长大。
- **选择优先于地图密度**：首页先回答“今天去哪 / 现在做什么”，再让用户进入完整地图。点位数量不能成为第一眼的噪音。
- **干净优先于变现**：任何商业化都不能污染地图浏览体验。
- **慢内容优先于热闹功能**：地点、推荐语、照片、日记比排行榜、评论区、广告合作更重要。
- **默契优先于社交压力**：连接应该轻、含蓄、有余地，不做强关注、强私信、强社交关系链。
- **创作者信念优先于外部建议**：社区朋友的建议可以参考，但不能让产品漂移成自己不想维护的东西。

## Test Plan

- 用三个问题过滤后续功能：
  - 这个功能会让地图更有人味，还是更像大众点评？
  - 这个功能会让用户更想留下真实经验，还是只是在消费信息？
  - 这个功能是在帮助社区成员表达和沉淀生活，还是在逼用户给平台补数据？
  - 如果一年后继续维护它，我会更喜欢这个产品，还是更厌烦它？
- 对当前未来更新列表做一次重排：
  - 优先：decision-first 首页、精选点位、场景入口、路线入口、当前位置可见性。
  - 保留：照片体验、日记模式、贴纸/盖章、探索模式、正在清迈。
  - 延后：LLM 路线规划、商家合作、复杂评论系统。
  - 谨慎：任何排行榜、广告位、批量商业 POI。

## Assumptions

- 当前目标不是最快变现，而是先守住 CMI Map 的产品灵魂。
- NCC 路演需要展示一个有独特信念的产品，而不是一个“什么都能加”的功能集合。
- 这次方向思考值得后续写入知识库。
